About The Class

Note: Every student must provide their own laptop. A laptop isn't necessary for class, as notes can be taken home, but hands on learning is more effective!

Each class we will start from scratch in Pico-8 education edition. Pico-8 Education Ediiton Classes are 4-hours in length, during which we will begin constructing our games using the built-in sprite, map, and code editor within the pico-8 game engine.

What We Will Build

All kinds of games! Each class will focus on a different type of game mechanic: top-down rpg, platformer, roughlike, fighting, racing, golfing, etc.

Games may not get finished! But you can always work on them again in a different class if you wish!
